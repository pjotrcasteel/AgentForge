AgentForge recommends a bounded first milestone, explicit tests and dependency checks.

Simple commands for everyday work.

With the .NET 10 SDK and source checkout, run setup once and then supply just your task.

# One-time settings: provider, model, optional allowance
dotnet run --project ./src/TokenBudget.Cli -- setup

# Your next task
dotnet run --project ./src/TokenBudget.Cli -- "Refactor the lighting engine"

# Or assess a Markdown plan
dotnet run --project ./src/TokenBudget.Cli -- preflight plan.md

Private by default.
The preflight does not upload prompt content, invoke a paid reviewer or execute code.

Honest about uncertainty.
Missing or stale prices and quotas remain unknown, not zero. Forecasts are not yet empirically calibrated.

Advanced .NET 10 architecture.
Reusable estimation domain, optional reviewer, CLI, local API, MCP integration and MSTest coverage.

Provider-neutral.
Copilot, OpenAI, Anthropic, Codex and ChatGPT are handled without transferring credits between platforms.
